## Что подготовить сейчас, пока идёт разработка

1. Финальные текстуры головы по скинам:
- Обычный (base)
- Бронзовый
- Серебряный
- Золотой

Рекомендация по файлам (PNG, прозрачный фон, 512x512):
- `head-common.png`
- `head-bronze.png`
- `head-silver.png`
- `head-gold.png`

2. Иконки валюты (медали ЛДПР):
- Обычная медаль (основная валюта)
- Редкая медаль (для будущего развития экономики)

Рекомендация: 256x256 PNG + уменьшенные версии 64x64.

3. Аудио-пак:
- 5-10 коротких фраз на старт (wav/mp3)
- Аплодисменты (после нового рекорда и последующего проигрыша)
- Короткий эффект покупки/разблокировки
- Звук редкой медали

Рекомендация по формату:
- `44.1kHz`, mono для коротких SFX, длительность 0.3-2.5 сек.

4. Контент для цитат Жириновского:
- Список безопасных для UI коротких цитат (15-30 шт)
- Отдельно отметить «цитаты для нового рекорда» (5-10 шт)

5. Таблица баланса экономики:
- Награда за прохождение барьера: сколько медалей
- Шанс выпадения редкой медали
- Цены скинов:
  - Бронзовый
  - Серебряный
  - Золотой

6. Система достижений (контент):
- Название достижения
- Условие
- Награда (если есть)

Минимальный стартовый набор:
- Первый полёт
- 10 очков за забег
- Новый рекорд
- 100 медалей накоплено
- 10 нажатий по голове (пасхалка)

7. Визуальные элементы для победы/ивентов:
- Конфетти-эффект (если будет спрайтовый)
- Эмоции головы (обычное, удар, поражение, рекорд)

8. UI-текст финальных формулировок:
- Кнопка покупки: `Сафонов, оплатить!`
- Названия режимов скорости
- Названия бонусов (в т.ч. двойной прыжок)

## Что уже можно считать технически определённым

- Локальный рекорд сохраняется в браузере (`localStorage`).
- Будет внутриигровой магазин с разблокировкой скинов за медали.
- Будет доска достижений.
- Будет система редких монет как фундамент для дальнейшего развития.
- Будут режимы скорости и редкий бонус «двойной прыжок».
