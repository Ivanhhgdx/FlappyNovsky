# FlappyNovsky - ЛДПР

HTML5-игра в стиле Flappy Bird с прогрессией, магазином и системой достижений.

## Запуск

### Вариант 1: напрямую
Открой `/Users/ivanfomin/ldpr-flappy-game/index.html` двойным кликом.

### Вариант 2: через сервер
```bash
cd /Users/ivanfomin/ldpr-flappy-game
python3 -m http.server 4173
```
Открой: `http://localhost:4173`

## Управление

- `Space`, клик или тап: старт / прыжок / рестарт
- `P`: пауза / продолжение
- `Esc`: выход в меню
- `F`: fullscreen

## Ключевые фичи

- Главное меню с разделами
- Внутриигровой магазин
- Валюта: медали ЛДПР + редкие медали
- Кнопка покупки: `Сафонов, оплатить!`
- Скины: обычный, бронзовый, серебряный, золотой
- Пасхальный секретный скин (10 кликов по голове в меню)
- Цитаты после событий (например, новый рекорд)
- Локальный рекорд (localStorage)
- Система достижений (доска достижений)
- Режимы скорости
- Редкий бонус: двойной прыжок
- Анимация победы (конфетти)
